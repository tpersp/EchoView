# Calibration reference image

`echoview-calibration-pal.png` is a 720x576 reference capture of EchoView's
generated calibration pattern: grid, outer border, 5%/10% inset marks and green
circle. It can be reused as a visual reference or a basis for future placeholder
artwork.

The live pattern is already selectable through **Calibration Pattern** display
mode and is generated by `DisplayWindow.show_calibration_pattern()` in viewer.py.
Prefer that mode for calibration: it adapts to output size, physical display aspect
and safe areas. This PNG has PAL 4:3 pixel-aspect compensation baked in, so the
circle appears slightly oval when viewed using square pixels; it should be round
on the intended 4:3 PAL display. It is not currently the automatic empty-media
placeholder.

`echoview-calibration-pal-colour.png` is the updated Pi capture with seven nominal
75% RGB bars (white, yellow, cyan, green, magenta, red, blue) and eight grayscale
steps. The original capture above is retained. The live pattern now includes both
rows while retaining the grid, overscan borders and physical-aspect circle.
These are visual troubleshooting aids, not a certified broadcast test signal;
actual PAL encoding and colour decoding need a colour display or measurement.
