Authorize Spotify

A quick setup guide

Connect once, then choose Spotify on a display.

1 Create an application

Open the Spotify Developer Dashboard, create an application, and copy its Client ID. A Client Secret is unnecessary with PKCE. Development mode requires the app owner to have Spotify Premium; other accounts must be allowed in the app settings.

2 Register your callback

Register the exact Redirect URI. Use an HTTPS controller address ending in /callback, or explicit loopback such as http://127.0.0.1:8080/callback. HTTP LAN addresses and localhost are not accepted.

3 Save and authorize

Save your details, then choose Authorize Spotify. Use the same browser and controller address throughout the flow; authorization expires after ten minutes. Switching methods requires authorization again. Check connection tests token refresh and API access.

4 Connecting from another computer

For loopback authorization, run ssh -N -L 8080:127.0.0.1:8080 user@PI-IP, then open http://127.0.0.1:8080/configure_spotify. Keep the tunnel open through the callback and do not edit the callback address. Alternatively, use your HTTPS controller address throughout.
