Configure Spotify Integration

{{ spotify_status }}
1. Spotify Developer Dashboard

Visit the Spotify Developer Dashboard and log in (or sign up if you don't have an account).

2. Create a New Application

After creation, note down your Client ID and Client Secret. In your app settings, set the Redirect URI to something like https://your-controller.example/callback, or http://127.0.0.1:8080/callback with SSH forwarding. Register the exact URI. HTTP LAN addresses and localhost are not accepted.

3. Enter Your Config Below

Fill in Client ID, Client Secret, Redirect URI, and the desired Scope, then click "Save Spotify Settings".

4. Authorize & Use

Click Authorize Spotify to begin the OAuth flow. Use the same browser and controller address throughout authorization. For a remote browser with loopback, first run ssh -N -L 8080:127.0.0.1:8080 user@PI-IP, then open http://127.0.0.1:8080/configure_spotify to start. Keep the tunnel open through the callback. Do not edit the callback address. Alternatively use your HTTPS controller address for the entire flow. Authorization expires after ten minutes. After connecting, use Check Connection to test token refresh and API access.
